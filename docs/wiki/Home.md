# GrooveScripting Wiki

GrooveScripting is an offline command-line drum, bass and lead synthesiser with sequencing, deterministic variation, automation,
MIDI interchange, mixing, effects, playback and WAV inspection. It is built for reproducible loops and shell-based arrangements.
Python 3.10+; MIT licence.
