Effect object reference

Pass each object through a repeated --effect flag. Every object requires type. Effect processing uses float audio; normalize or limit before integer export when needed.

TypeProperties / boundsDefaults
gaindb [-120, 60]db=0
fadein_seconds ≥0; out_seconds ≥0both 0
lowpasshz [1, sample_rate/2-1]; resonance [0,1]hz=1000; resonance=0
saturationdrive [0.001,100]drive=1
delayseconds [0.001,30]; feedback [0,0.999]; mix [0,1]; repeats integer [1,64]seconds=0.25; feedback=0.4; mix=0.3; repeats=8
reverbseconds [0.001,30]; mix [0,1]; decay [0,0.999]seconds=1; mix=0.3; decay=0.5

cut keeps the original timeline; full preserves the generated tail; wrap folds the tail onto the original loop. Reverb uses a deterministic multitap approximation.
