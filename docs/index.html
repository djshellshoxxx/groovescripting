01 / SETUP

From source to sound

Requires Python 3.10+. Choose your platform below. Git is only needed for cloning; source ZIP users can extract the download, open its directory and start at the virtual-environment command.

Linux · Ubuntu / Debian
sudo apt update
sudo apt install python3 python3-venv git libportaudio2 libsndfile1
git clone https://github.com/djshellshoxxx/groovescripting.git
cd groovescripting
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install ".[playback]"
groovseq examples/grooves/house.json --output house.wav
groovplay house.wav

Check python3 --version first. In later terminals run source .venv/bin/activate from the checkout. Other distributions need equivalent Python, Git, PortAudio and libsndfile packages. Offline rendering only: install . instead of .[playback].

Windows · PowerShell or Command Prompt

Install Python 3.10+ and Git for Windows, then reopen your terminal. Check py -3 --version and git --version.

git clone https://github.com/djshellshoxxx/groovescripting.git
cd groovescripting
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install --upgrade pip
.\.venv\Scripts\python.exe -m pip install ".[playback]"
.\.venv\Scripts\groovseq.exe examples/grooves/house.json --output house.wav
.\.venv\Scripts\groovplay.exe house.wav

These commands use the virtual environment directly and need no PowerShell activation. Reuse the same executable paths in later sessions. If py is unavailable, use your installed python command to create the environment.

Full installation, updates, uninstall and troubleshooting guide. Rendering works without audio hardware; playback needs a local output device. On Linux use groovplay --devices; on Windows use .\.venv\Scripts\groovplay.exe --devices.

Patterns use . for a rest. Drum hits use x; synth patterns use note names such as C2 and Eb4. Quote patterns so your shell keeps them together. See the complete argument reference for defaults and ranges, and the downloaded specifications for the full pattern grammar. Each command’s --help lists its accepted options.

02 / TOOLKIT

Eight instruments and helpers

groovdrm

Drum sequencer

Build a drum loop from kick, snare, closed_hat, open_hat, clap, tom and rim voices.

groovdrm --bpm 140 --bars 2 --voice kick --pattern "x...x...x...x..." --output kick.wav

--voice, --drum-pattern VOICE=PATTERN, --drum-param VOICE.KEY=VALUE

groovbss

Bass synthesizer

Render bass notes with envelopes, filtering, glide and modulation.

groovbss --bpm 140 --bars 2 --pattern "C2 . G1 . C2 . Bb1 ." --waveform saw --output bass.wav

--waveform, --attack, --decay, --sustain, --release, --cutoff, --resonance, --glide, --legato, --sub-mix, --detune, --pulse-width, --saturation, --lfo-rate, --lfo-depth, --filter-attack, --filter-decay, --filter-sustain, --filter-release, --filter-amount

groovld

Lead synthesizer

Render melodic phrases with polyphony, unison, vibrato and arpeggiation.

groovld --bpm 140 --bars 2 --pattern "C4 . Eb4 . G4 . Bb4 ." --waveform saw --output lead.wav

Synthesis flags plus --voices, --unison, --unison-detune, --vibrato-rate, --vibrato-depth, --arp, --arp-rate

groovmix

WAV mixer

Combine rendered WAV tracks with independent gain, pan and offsets.

groovmix kick.wav bass.wav lead.wav --normalize --output groove.wav

--track-gain, --track-pan, --track-offset, --trim, --track-mute INDEX, --track-solo INDEX, --normalize, --limit, --stems

groovseq

Project renderer

Render a JSON project containing tempo, tracks and synthesis parameters.

groovseq examples/first-groove.json --output groove.wav --stems stems

PROJECT, --stems DIR

groovfx

Effects processor

Apply a chain of effects to an existing WAV. Effects are specified as JSON objects.

groovfx groove.wav --effect '{"type":"gain","db":-2}' --output quieter.wav

FILE, --effect JSON (repeat for a chain)

groovplay

Playback and diagnostics

Play WAV audio, enumerate devices, diagnose playback support or generate a test tone.

groovplay groove.wav --repeat 2

FILE, --devices, --diagnose, --test-tone, --repeat N

groovinfo

Audio inspector

Inspect WAV metadata and signal statistics in text or JSON.

groovinfo groove.wav --json

FILE, --json

05 / DIAGNOSTICS

Keep the evidence with the render

Add --log-file to record a command’s troubleshooting details. Debug logging is useful when reporting failed renders or device selection problems. Text is convenient for reading; JSON is convenient for scripts.

groovseq examples/first-groove.json --output debug.wav --log-file render.log --log-level debug --log-format text
groovplay --diagnose --log-file playback.jsonl --log-level debug --log-format json

Include your command, log, OS, Python version and project file in a bug report. Keep the seed and sample rate fixed when reproducing a problem. If playback fails, first render a WAV and inspect it with groovinfo, then list devices with groovplay --devices. OS audio policies and hardware vary; local device and volume tests remain necessary.

PATTERNS / GROOVE COOKBOOK

Ten formulas to start from

Complete four-bar projects with drums, bass and lead. Render from the repository root after installing. These are editable starting points for each style.

In 4/4, subdivision 4 gives 16 steps per bar: beats begin at steps 1, 5, 9 and 13. x is a drum hit, X an accent and . a rest. Notes are space-separated steps; C2:0.5 lasts half a beat and C4+Eb4+G4 is a chord. A longer note still advances the pattern by one step.

Step seconds = 60 / (BPM × subdivision). Loop seconds = bars × beats × 60 / BPM. Patterns repeat to fill the project. Swing delays alternating steps by swing / (2 × subdivision) beats.

The commands below work in Bash and PowerShell with the environment active. With the Windows setup above, prefix each tool with .\.venv\Scripts\ and append .exe. Use a new output filename or add --overwrite for repeat renders.

Useful recipes

All of these offline commands are exercised by the downloadable examples/smoke.py script. It writes its results to a separate output directory.

Single hit
groovdrm --voice snare --pattern "x..............." --bars 1 --output single-hit.wav
Glide and accent
groovbss --pattern "C2:0.5:1 ~ G2! ." --glide 0.08 --legato --output glide.wav
Chord arpeggio
groovld --pattern "C4+Eb4+G4:1 . . ." --arp up --arp-rate 0.25 --normalize --output arp.wav
Wrapped delay loop
groovfx groove.wav --effect '{"type":"delay","seconds":0.214,"mix":0.2,"feedback":0.35}' --tail wrap --output delay-loop.wav
Playback device discovery
groovplay --devices
groovplay --diagnose
groovplay --test-tone --device 0
